# OSTF 4.2.0 — 適合性と実装範囲

規格の正式版、文書のSchema適合、意味規則適合、保存可能なEditor、変換器の出力、実アプリの読み込み成功は別の主張です。

| 主張 | 必要な範囲 |
|---|---|
| 構造適合 | 厳格なJSONと宣言版Schema |
| 意味適合 | 所有関係、ID/参照、時間、値域、重複、曲線等の規範条件 |
| 保存可能なReader/Editor | 版の明示認識と無断欠損の防止 |
| MIDI再生 | 継承Notes/MIDIの時刻・Channel等。歌唱Curveを勝手に加算しない |
| 歌唱Adapter | Voiceの明示選択と未対応・近似・曖昧さの報告 |
| 外部ソフト対応 | 別途そのアプリ固有の証拠が必要。本版では主張しない |

## 収録範囲

4.2.0 Core規格、全網羅マニュアル/リファレンス、Schema、デモ、読取専用の静的監査ツールを収録します。Native Writer、DAWデバイス、音声合成エンジン、Voicebank、アプリ画面の証拠は収録しません。外部動作検証は依頼範囲外で、Synthesizer V・OpenUtau・VOCALOID・CeVIO・LibreSVIPの実動作確認済みとは記載しません。

## 変換実装の位置付け

開発資料にはUFDATAの参考出力、SVP/USTXの実験的出力がありましたが、本規格配布物には含めません。VPR/VSQX/CCSは将来の候補で、ここで実装済みとは扱いません。Coreの意味を変えずに、独立したAdapterを実装できます。

## 安全な読込

instruction、Vendor data、URI、歌詞、説明文は信頼済み命令ではありません。読み込みだけでコード実行、AIツールの実行、ネットワーク取得、音源のロード、外部アカウント変更を行いません。Schema参照はローカルで解決できます。未知情報を勝手に権限へ昇格させず、保存不能なら破壊的な上書きを拒否します。

## 記録の読み方

今回の静的報告は配布物の作成時に確認した内容だけを示します。過去の回帰テスト件数を今回再実行した結果へ読み替えません。項目網羅は実ファイル内の掲載位置を示すもので、すべての値・全意味規則・音楽品質・音響一致を試したものではありません。
