# Changelog

## 4.2.0 — 2026-11-11

- Freeze the optional vocal interchange layer without changing inherited instrumental MIDI semantics.
- Publish integrated English/Japanese Core manuals, normative text and full schema references.
- Include 53 version-4.2 `.ostf` examples, with witnesses for all 569 reachable named field declarations.
- Separate ordinary authoring, legacy preservation, ambiguous export examples and musical arrangements.
- Adopt the existing specification CC0 / software MIT distribution split.
- Keep external adapter/app certification outside the specification release.
- Correct the inherited wordless-humming example's primary lyric document reference to its actual `doc-wordless` declaration.

## 4.1 compatibility lineage

The inherited 4.1 schema and published manuals formed the baseline. The original schema bytes are retained separately. Its Track Directions and MIDI semantics are preserved, not redefined by vocal expression.
